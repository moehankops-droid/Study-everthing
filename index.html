📚 English Basic Tenses

1. Present Simple Tense

အမြဲလုပ်လေ့ရှိသော၊ သဘာဝအတိုင်းဖြစ်ပျက်သော အရာများ။

Subject + V1 (s/es) + Object

ဥပမာ: She speaks English very well.

2. Past Simple Tense

အတိတ်ကာလက ဖြစ်ပျက်ပြီးဆုံးသွားသော အလုပ်များ။

Subject + V2 + Object

ဥပမာ: He went to school yesterday.

3. Future Simple Tense

အနာဂတ်တွင် ဖြစ်လာမည့် အရာများ။

Subject + will + V1 + Object

ဥပမာ: I will study English tomorrow.

4. Present Continuous Tense

ယခုလက်ရှိ ဖြစ်ဆဲဖြစ်သော အလုပ်များ။

Subject + is/am/are + V(ing) + Object

ဥပမာ: They are playing football now.

5. Past Continuous Tense

အတိတ်တွင် အချိန်တစ်ခုခု၌ ဖြစ်ဆဲဖြစ်သော အရာများ။

Subject + was/were + V(ing) + Object

ဥပမာ: I was reading a book yesterday.

6. Future Continuous Tense

အနာဂတ်တွင် ဆက်လက်ဖြစ်ပွားနေမည့် အလုပ်များ။

Subject + will be + V(ing) + Object

ဥပမာ: She will be sleeping at this time tomorrow.

7. Present Perfect Tense

ယခုတလောမှ ပြီးဆုံးသွားသော လုပ်ရပ်များ။

Subject + has/have + V3 + Object

ဥပမာ: I have finished my homework.

8. Past Perfect Tense

အတိတ်က အခြားအဖြစ်အပျက်တစ်ခု မတိုင်မီ ပြီးစီးသွားခဲ့သော အရာများ။

Subject + had + V3 + Object

ဥပမာ: The train had left before we arrived.

9. Future Perfect Tense

အနာဂတ် သတ်မှတ်ချိန်တစ်ခု မတိုင်မီ ပြီးစီးမည့် အလုပ်များ။

Subject + will have + V3 + Object

ဥပမာ: I will have passed Grade 8 by next year.
